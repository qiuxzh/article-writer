# article-writer

## 它做什么

article-writer 是一个用于写作的 AI skill。加载之后，它指导 AI 检查自己生成的文章，把里面的 AI 痕迹改掉。

例子：

| 原文 | 改写后 | 问题 |
|------|--------|------|
| 真正的壁垒不是技术，而是认知。 | 真正的壁垒是认知。 | 翻案腔 |
| 他找到了一条路——一条所有人都忽略的路。 | 他找到了一条别人都没注意的路。 | 破折号滥用 |
| 这相当于为团队配备了一个永不疲倦、秒级响应的初级审查员。 | 它不会疲倦，响应在秒级，能承担初级审查的活。 | 拟人化喻体 |
| 一句话总结：这个方案成本太高。 | 这个方案成本太高。 | 冒号滥用 |

改写只动命中的句子，没命中的逐字保留。文章结构和观点不动，原文的事实和数据不增不减，改写后的每个实词都能在原文找到出处。

## 适用

博客、知乎等网络文章的成稿清理。其他体裁不在范围内。

## 使用

把 SKILL.md 放进 skills 目录，或直接把文章发给 agent 处理。
